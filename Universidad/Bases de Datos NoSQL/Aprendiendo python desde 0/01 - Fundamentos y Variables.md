## ¿Qué es Python y para qué sirve?
Python es un lenguaje de programación muy popular por que se lee casi como si fuera texto en inglés, lo que lo hace ideal para comenzar.

Se utiliza principalmente para:
- **Desarrollo web:** Crear sitios y aplicaciones en internet.
- **Inteligencia Artificial y Ciencia de Datos:** analizar información y entrenar modelos.
- **Automatización:** Crear pequeños programas que hagan tareas repetitivas para nosotros.

# 1. Mostrar texto en pantalla (`print`)
La función `print()` sirve para que el programa muestre un mensaje en la terminal.

```
print("¡HO hola soy German!")
```

*El texto siempre debe de ir entre comillas (pueden ser dobles `""` o simples `''`)*

# 2. Guardar datos en variables
Una variable es como **una caja con una etiqueta** donde guardamos **un valor** para usarlo después.
No necesitamos declarar el tipo de dato, Python lo **detecta automáticamente.**

```
nombre = "ING Sebastián" # Texto (string)
edad = 22                # Número entero (int)
altura = 1.74            # Número decimal (float)
activo = True            # Booleano (True o False) 
```

# 3. Tipos de datos más comunes 

| Tipo         | Nombre  | Ejemplol         |
| ------------ | ------- | ---------------- |
| **Texto**    | `str`   | `Hola`, `Python` |
| **Entero**   | `int`   | `10`, `-5`, `0`  |
| **Decimal**  | `float` | `3.14`, `0.5`    |
| **Booleano** | `bool`  | `True`, `False`  |

# 4. Recibir datos del usuario (`input`)
La función `input()` pausa el programa y espera a que el usuario escriba algo en la terminal.

```
nombre_
```
